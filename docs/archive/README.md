# Historical documentation

This directory preserves implementation notes, hardening reports, retrospectives,
and release-risk snapshots that were useful while the translation pipeline was
being recovered and stabilized. They are **not current operating instructions**.

Use [`../README.md`](../README.md) for the maintained documentation map. Git history
remains the authoritative record for deleted code, removed command surfaces, and
earlier versions of files. Archived documents intentionally retain historical
terminology and may mention commands, paths, test counts, candidate hashes, or
translation wording that no longer exists in the maintained tree.
