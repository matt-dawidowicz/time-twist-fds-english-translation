# Full-word menu candidate results — 2026-08-12

This is the measured result of applying the all-record target map without
moving any fixed UI record or relaxing the native 31-entry dictionary limit.

## Candidate result

- Fixed records audited: **721**
- Full target rendered literally: **252**
- Full target rendered through the rebuilt bank dictionary: **122**
- Explicit fixed-slot/dictionary blockers: **347**
- Unexplained label mismatches: **0**

The candidate's `release_manifest.json` pins the four-side FDS hash, each
scenario-bank hash, source lock, code provenance, and per-bank compression
figures. Its reports are generated by these fixture-aware commands:

```text
python work/tools/audit_full_word_menu_targets.py --output-csv <output>/full_word_target_source_audit.csv
python work/tools/audit_fixed_menu_labels.py --candidate-fds <candidate.fds> --targets-csv docs/full_word_menu_targets_all_records.csv --output-csv <output>/fixed_menu_label_audit.csv
python work/tools/report_full_word_menu_candidate.py --audit-csv <output>/fixed_menu_label_audit.csv --manifest-json <output>/release_manifest.json --output-dir <output>
```

The resulting CSV files separate literal full words, dictionary-rendered full
words, and every remaining blocker. A blocker decodes to an audited previous
label and is marked `blocked`; it is never reported as a full-word success.

## Why there are blockers

Fixed command, object, and choice labels have individual original byte slots.
The normal scenario text shares a maximum 31-entry dictionary with those
tables. Reserving many new menu-only words forces out high-value dialogue
tokens; complete rebuilt banks then exceed their original RAM footprint. A
priority-first exhaustive reservation search was allowed to run for five
minutes and was stopped by its guard rather than accepting an unbounded build.

This leaves two safe future paths:

1. Find a smaller, bank-specific set of additional reservations and prove it
   with a complete bank rebuild plus candidate audit.
2. Design a separate, runtime-tested table-relocation or renderer project.

Neither is a text-only edit. Until one is proven, the candidate preserves the
original table footprint and names the short label in `fixed_menu_label_blockers.csv`.
